# Radar CNPJ

Brazilian company-data service built on the Receita Federal CNPJ registry. Paste a business idea in plain text to see how many companies already operate in that space, plus CNPJ lookup, advanced search, geolocation, and change-monitoring. Explicitly agent-first, shipping a full stack of machine-readable discovery artifacts including OpenAPI, a hosted MCP server, and llms.txt.

## APIs

- **Radar CNPJ API** — Public REST API over the Brazilian CNPJ registry: business-idea evaluation, CNPJ lookup, advanced search/export, free-text-to-filters IA translation, geolocation, and anonymous monitoring. Mostly no-auth core; paid operations use the x402 (USDC on Base) HTTP 402 payment protocol. OpenAPI 3.1 with 29 documented paths. (`https://radar-cnpj.com`)

> Multiple publicly verified surfaces: REST API (OpenAPI 3.1 at /openapi.json), hosted Streamable HTTP MCP server at https://radar-cnpj.com/mcp (JSON-RPC 2.0, 13 tools), and llms.txt + llms-full.txt. Additional discovery via RFC 9727 api-catalog at /.well-known/api-catalog (application/linkset+json), an OKF bundle at /okf/index.md, apis.json at /apis.json and /.well-known/apis.json, and an MCP registry-auth key at /.well-known/mcp-registry-auth.
